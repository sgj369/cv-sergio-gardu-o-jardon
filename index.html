Proyectos

EcoGuía SOS — Plataforma Web Full Stack

2024 – Presente · Remoto / CDMX

Plataforma SPA/PWA integral de impacto ambiental que conecta organizaciones, actores locales y voluntarios mediante herramientas interactivas e iniciativas verdes verificadas.

  • Arquitectura SPA/PWA responsiva construida con Vue 3, TypeScript, Vite, Pinia y Vue Router, optimizada para computadora, tablet y móvil.
  • Mapas interactivos geoespaciales con MapLibre, geolocalización, búsqueda de rutas y puntos de interés ecológico.
  • Autenticación completa y permisos granulares por rol (RBAC) para Administradores, Actores y Voluntarios con flujos de aprobación y moderación.
  • Notificaciones en tiempo real, centro de soporte y pipeline de carga/optimización de imágenes integrando Supabase Storage y Cloudflare R2 (compatible con S3).
  • Calidad y seguridad: validación con Zod, pruebas unitarias e integración con Vitest y jsdom, monitoreo de errores con Sentry, Vercel Analytics, Speed Insights y Row Level Security (RLS) en PostgreSQL.
  • Flujos de integración continua (CI/CD) en GitHub Actions con verificación estricta de TypeScript, tests automatizados y builds de producción optimizados.
Vue 3 TypeScript Vite Pinia Vue Router Supabase PostgreSQL Cloudflare R2 MapLibre Vitest Zod GitHub Actions

Sistema IoT Autónomo para Techos Verdes — Proyecto de Tesis

2023 – 2025 · Validado en campo

Diseño y despliegue de un sistema de monitoreo térmico y ambiental autónomo para cuantificar el impacto microclimático en techos verdes urbanos.

  • Desarrollo de nodos de sensado con microcontroladores ESP32 y sistema de alimentación fotovoltaica con gestión de baterías para operación continua.
  • Implementación de pipeline de datos y dashboard telemétrico con sincronización en Google Sheets / SQL y procesamiento analítico en Python (pandas).
  • Validación estadística en campo que demostró reducción significativa de temperatura y mitigación de islas de calor urbanas.
ESP32 Arduino / C++ Sensores ambientales Energía solar & baterías Python (pandas) Google Sheets API Google Apps Script
